# Mehik Kumari | Personal Portfolio Website
Welcome to the official repository of my personal portfolio website. This website showcases my skills and experience as a **MERN Stack Developer and UI/UX Designer**, along with my academic background, professional experience, certifications, and featured projects.

**Live Website:**
https://maheknankani.github.io/Mehik_Kumari-Portfolio_Website/
---
## Features

* Modern dark-themed UI with glassmorphism effects and animated backgrounds.
* Interactive work experience timeline with certificate preview modals.
* Certifications section with full-screen certificate previews.
* Project showcase with technology tags, live demos, and source code links.
* Dynamic typewriter animation highlighting technical skills.
* Fully responsive design for desktop, tablet, and mobile devices.
* Contact section with email and social media links.
* Smooth animations and interactive navigation.
