Welcome to the official repository of my personal portfolio website! This interactive web application showcases my skills as a **MERN Stack Developer & UI/UX Designer**, featuring my academic background, work experience, technical certifications, and featured web development projects.

🌐 **Live Website Demo**: [https://maheknankani.github.io/Mehik_Kumari-Portfolio_Website/](https://maheknankani.github.io/Mehik_Kumari-Portfolio_Website/)

---

## ✨ Features

- **🚀 Cyberpunk & Modern Dark UI**: Sleek glassmorphism theme, glowing gradients, animated wallpaper backgrounds, and smooth micro-interactions.
- **💼 Work Experience Timeline**: Detailed timeline of virtual internships (10Pearls, CodeAlpha, Elevvo Pathway) with interactive **Certificate Modal Preview** popups.
- **📜 Certifications Grid**: Interactive showcase of technical credentials with instant full-screen image previews.
- **💻 Projects Showcase**: Filterable portfolio projects featuring live demo links, source code repositories, and tech stack tags.
- **⌨️ Dynamic Typewriter Animations**: Smooth typing effect displaying real-time technical capabilities.
- **📱 100% Responsive Design**: Pixel-perfect layout optimization for desktop, laptop, tablet, and mobile displays.
- **✉️ Direct Contact Section**: Easy-to-use contact form, direct email links, and social media channels.

## 💻 Local Setup & Development

To run this project locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/maheknankani/Mehik_Kumari-Portfolio_Website.git
   ```

2. **Navigate to the Directory**:
   ```bash
   cd Mehik_Kumari-Portfolio_Website
   ```

3. **Open with Live Server**:
   Open `index.html` in your browser or run with VS Code's **Live Server** extension.
